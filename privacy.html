Privacy policy

This policy describes Omarchy Drive, the personal rclone and Flea desktop configuration maintained by henrykkng.

Data accessed and purpose

After the owner authorizes Google access, rclone accesses Google Drive file contents and metadata, including names, folder structure, identifiers, sizes, and modification information. It uses this information to display files and perform the owner's requested operations, including reading, downloading, creating, uploading, editing, moving, renaming, and deleting files and folders.

The integration requests Google Drive read and write access. Google account authorization is handled by Google in the browser; the integration does not request or store the owner's Google password.

Local storage and retention

OAuth credentials and tokens are stored in the local rclone configuration with owner-only file permissions. Rclone may retain file metadata in memory and temporarily cache file content on the owner's computer, including writes waiting to upload. Downloads and copies explicitly saved by the owner remain where the owner stores them.

Temporary cache retention is managed by rclone's cache settings. Files waiting to upload may be kept longer. Credentials remain until removed or replaced, and downloaded files remain until deleted by the owner.

Sharing and use

Drive requests are sent to Google's services. The configuration does not operate a separate hosted backend for Drive content and does not sell Drive data or use it for advertising. The owner can intentionally copy files to other locations or open them in other applications; those destinations and applications have their own data practices.

The maintainer does not use Google user data obtained through this integration for model training, advertising, or unrelated analytics.

Control and deletion

The owner can stop the mount at any time and revoke the app's access in Google Account connections. Revocation prevents future authorized access but does not delete files or cached copies already stored on the computer.

Removing local authorization credentials or cached data is a separate action on the owner's computer. Pending uploads should finish before removing cache data. Deleting a file through the mounted Drive can affect the actual file in Google Drive.

This website

This site is informational and has no Google sign-in, forms, advertising, analytics scripts, or application cookies. It is hosted on GitHub Pages. GitHub records visitors' IP addresses for security purposes as described in the GitHub Privacy Statement. Public GitHub issue submissions are subject to GitHub's policies.

Contact and changes

Questions can be directed to the maintainer through the site repository's issue tracker. Do not include credentials, tokens, or private Drive data in public issues. This policy will be updated if the integration's data practices change.
