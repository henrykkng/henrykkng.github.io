# Omarchy Drive information pages

Static homepage, privacy policy, and terms for henrykkng's personal Google Drive OAuth client and rclone/Flea desktop integration.

Intended GitHub Pages address: https://henrykkng.github.io/

Publish the main branch's root directory with GitHub Pages. There is no build step, JavaScript, or application backend.

Google Search Console ownership can be verified by adding Google's supplied HTML verification file to this directory, or adding its verification meta tag to index.html. Use the Google account that owns the OAuth project.
