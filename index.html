Personal desktop integration

Your Google Drive.
Your desktop.

Omarchy Drive is a personal configuration maintained by henrykkng. It uses rclone to mount the owner's Google Drive on an Omarchy Linux desktop, where Flea provides file management.

What it does

The owner can browse, open, download, upload, create, rename, move, and delete Drive files and folders through the mounted folder. Native Google Docs, Sheets, and Slides are presented as links that open in a browser.

Why Google Drive access is requested

Google authorization allows rclone to read file contents and metadata and carry out the owner's requested file operations. This configuration requests Drive read and write access so it can manage existing files, as well as create new ones.

Where it runs

The integration runs on the owner's computer. Authorization credentials and temporary file caches are stored locally. This informational website does not connect to Google Drive, accept credentials, or provide a sign-in service.

Personal use

This is a personal setup, not a public file-hosting service. It is not affiliated with Google, Omarchy, rclone, or Flea.
